### **Part 1: The Teaching Strategy - How to Approach These Problems**

Before diving into the specific solutions, here's the general method you should teach your student. The key is to turn the block of text into a visual diagram.

**The Core Concept: 3-Set Venn Diagrams**

1.  **Draw the Diagram First:** Always start by drawing three overlapping circles. Label them clearly (e.g., Olympics, Asiad, CWG).

2.  **Understand the 8 Regions:** A 3-circle Venn diagram has 8 distinct regions. It's crucial to understand what each one represents:
    *   **Region 1, 2, 3:** Only A, Only B, Only C (participants in exactly one event).
    *   **Region 4, 5, 6:** A and B only, B and C only, A and C only (participants in exactly two events).
    *   **Region 7:** A and B and C (participants in all three events). This is the centermost region.
    *   **Region 8 (Outside the circles):** None of the three.

    

**The Golden Rule: Start from the Inside Out**

The most effective strategy is to fill the diagram starting from the most specific information and moving to the most general.
1.  **Fill "All Three":** The first value you should always look for is the number or percentage of people who participated in all three categories (Region 7).
2.  **Fill "Exactly Two":** Next, find the values for those in "A and B *but not* C" (Region 4), "B and C *but not* A" (Region 5), etc.
3.  **Use Total Information to Find "Only One":** The text often gives the total for an entire circle (e.g., "50% participated in Olympics"). This total is the sum of four regions (Only O + O&A only + O&C only + All three). You can use this to calculate the "Only" region by subtracting the other three known values.

**Key Vocabulary to Master:**

*   **"A and B"**: This means the entire overlapping area of circles A and B. It includes people who did A, B, *and* C. So, `(A and B) = (A and B only) + (All three)`.
*   **"A and B, but not C"** or **"Only A and B"**: This is specific. It refers to only the intersection of A and B, excluding the center (Region 4).
*   **"At least two"**: The sum of the three "exactly two" regions plus the "all three" region.
*   **"Exactly one"**: The sum of the three "only" regions.
*   **"A but not B"**: Everyone in circle A minus the entire intersection of A and B.

### **Set 1: Sportsmen (Q.1 - Q.5)**

**Information Breakdown & Diagram Setup**

*   Let Total Sportsmen = x
*   Let O = Olympics, A = Asiad, C = CWG.
*   Total O = 50%
*   Total A = 53%
*   Total C = 42%
*   O and A but not C = 10%
*   O and C but not A = 14%
*   A and C but not O = 5%

Let the percentage of sportsmen who participated in all three events be **p**.

**Step 1: Express "Only" regions in terms of 'p'.**
*   Total O = (Only O) + (O&A only) + (O&C only) + (All three)
    50% = (Only O) + 10% + 14% + p  =>  **Only O = 26% - p**
*   Total A = (Only A) + (O&A only) + (A&C only) + (All three)
    53% = (Only A) + 10% + 5% + p   =>  **Only A = 38% - p**
*   Total C = (Only C) + (O&C only) + (A&C only) + (All three)
    42% = (Only C) + 14% + 5% + p   =>  **Only C = 23% - p**

**Step 2: Find the value of 'p'.**
Assuming every sportsman participated in at least one game, the sum of all regions is 100%.
Total % = (Only O) + (Only A) + (Only C) + (O&A only) + (O&C only) + (A&C only) + (All three)
100% = (26-p) + (38-p) + (23-p) + 10 + 14 + 5 + p
100% = 116 - 2p
2p = 16
**p = 8%** (This is the percentage for "All three" events)

**Step 3: Calculate the final percentage for all "Only" regions.**
*   **All three** = 8%
*   **Only O** = 26% - 8% = **18%**
*   **Only A** = 38% - 8% = **30%**
*   **Only C** = 23% - 8% = **15%**

**Summary of Percentages:**
*   Only O = 18%
*   Only A = 30%
*   Only C = 15%
*   O&A only = 10%
*   O&C only = 14%
*   A&C only = 5%
*   All three = 8%
(Check: 18+30+15+10+14+5+8 = 100%. Correct.)

Now, we can answer the questions.

**1. If only Olympic Games is 81, what is the total number of sportsmen?**
*   We know "Only Olympic Games" is 18%.
*   So, 18% of Total (x) = 81
*   0.18 * x = 81
*   x = 81 / 0.18 = 450
*   **Answer: (c) 450**

**2. If exactly two events is 58, what is the number in all three events?**
*   "Exactly two events" = (O&A only) + (O&C only) + (A&C only) = 10% + 14% + 5% = 29%.
*   We are given this number is 58.
*   So, 29% of Total (x) = 58
*   0.29 * x = 58 => x = 200.
*   The question asks for the number in "all three events", which is 8%.
*   Number = 8% of 200 = 0.08 * 200 = 16.
*   **Answer: (a) 16**

**3. If x is equal to 300, how many participated in all three events?**
*   "All three events" is 8%.
*   Number = 8% of 300 = 0.08 * 300 = 24.
*   **Answer: (b) 24**

**4. If all three events is 48, what is the number of sportsmen in Asiad?**
*   "All three events" is 8%.
*   So, 8% of Total (x) = 48
*   0.08 * x = 48 => x = 600.
*   The question asks for the total number in Asiad, which is 53%.
*   Number = 53% of 600 = 0.53 * 600 = 318.
*   **Answer: (d) 318**

**5. If x is 300, what is the ratio of only Olympic Games to only CWG?**
*   Only Olympic Games = 18%
*   Only CWG = 15%
*   The ratio is 18% : 15%. We can ignore the total number (x) as it will cancel out.
*   Ratio = 18 : 15. Divide by 3 to simplify.
*   Ratio = 6 : 5.
*   **Answer: (d) 6 : 5**

### **Set 2: GK Class (Q.6 - Q.10)**

**Information Breakdown & Diagram Setup**

*   Total Students = 900
*   Let S = Sky News, N = NDTV, C = CNN.
*   All three (S ∩ N ∩ C) = 5% of 900 = 45.
*   Only CNN = 18% of 900 = 162.
*   S and C but not N = 15% of 900 = 135.
*   Total S = 40% of 900 = 360.
*   Ratio (Only CNN) : (Total CNN) = 9 : 29.
    *   162 / (Total CNN) = 9 / 29 => Total CNN = (162 * 29) / 9 = 18 * 29 = 522.
*   N but not S = 42% of 900 = 378. (This is Only N + N&C only)
*   N but not C = 30% of 900 = 270. (This is Only N + S&N only)

**Step 1: Fill the diagram with knowns.**
*   All three = 45
*   Only C = 162
*   S&C only = 135

**Step 2: Deduce the missing regions.**
*   **Find N&C only:**
    Total C = (Only C) + (S&C only) + (N&C only) + (All three)
    522 = 162 + 135 + (N&C only) + 45
    522 = 342 + (N&C only) => **N&C only = 180**
*   **Find Only N:**
    We know (N but not S) = (Only N) + (N&C only) = 378
    (Only N) + 180 = 378 => **Only N = 198**
*   **Find S&N only:**
    We know (N but not C) = (Only N) + (S&N only) = 270
    198 + (S&N only) = 270 => **S&N only = 72**
*   **Find Only S:**
    Total S = (Only S) + (S&N only) + (S&C only) + (All three)
    360 = (Only S) + 72 + 135 + 45
    360 = (Only S) + 252 => **Only S = 108**

**Summary of Student Numbers:**
*   Only S = 108
*   Only N = 198
*   Only C = 162
*   S&N only = 72
*   S&C only = 135
*   N&C only = 180
*   All three = 45
(Check: 108+198+162+72+135+180+45 = 900. Correct.)

Now, we answer the questions.

**6. (S&N only) is what percent of (N&C only)?**
*   (72 / 180) * 100% = (2/5) * 100% = 40%.
*   **Answer: (b) 40%**

**7. Boys only Sky News is approx what % of boys only NDTV India?**
*   Students who like only Sky News = 108. B:G = 5:4.
    *   Boys = (5/9) * 108 = 60.
*   Students who like only NDTV India = 198. B:G = 6:5.
    *   Boys = (6/11) * 198 = 6 * 18 = 108.
*   Percentage = (60 / 108) * 100% ≈ 55.55%. The closest option is 56%.
*   **Answer: (d) 56%**

**8. Ratio of (Sky News but not CNN) to (CNN but not Sky News).**
*   Sky News but not CNN = (Only S) + (S&N only) = 108 + 72 = 180.
*   CNN but not Sky News = (Only C) + (N&C only) = 162 + 180 = 342.
*   Ratio = 180 : 342. Divide both by 18.
*   Ratio = 10 : 19.
*   **Answer: (d) 10 : 19**

**9. Difference between (only one news channel) and (only two news channels).**
*   Only one = (Only S) + (Only N) + (Only C) = 108 + 198 + 162 = 468.
*   Only two = (S&N only) + (S&C only) + (N&C only) = 72 + 135 + 180 = 387.
*   Difference = 468 - 387 = 81.
*   **Answer: (c) 81**

**10. Average of (N&C only) and (S&N only).**
*   Average = (180 + 72) / 2 = 252 / 2 = 126.
*   **Answer: (c) 126**

### **Set 3: Agra Tourists (Q.11 - Q.15)**

**Information Breakdown & Diagram Setup**

*   Total Tourists = 800
*   Let T = Taj Mahal, R = Red Fort, F = Fatehpur Sikri.
*   Total T = 60% of 800 = 480.
*   All three (T ∩ R ∩ F) = (1/3) of Total T = (1/3) * 480 = 160.
*   Only F = 140.
*   Only T = 190.
*   Total R = Total F.
*   Key sentence: "Only R = (T&R only) + (T&F only)".

**Step 1: Fill the diagram.**
*   All three = 160
*   Only F = 140
*   Only T = 190

**Step 2: Deduce the missing regions.**
*   **Find the sum of (T&R only) and (T&F only):**
    Total T = (Only T) + (T&R only) + (T&F only) + (All three)
    480 = 190 + (T&R only) + (T&F only) + 160
    480 = 350 + (T&R only) + (T&F only)
    (T&R only) + (T&F only) = 130.
*   **Find Only R:**
    From the key sentence, Only R = (T&R only) + (T&F only). So, **Only R = 130**.
*   **Find R&F only:**
    Everyone visited at least one place, so the sum of all regions is 800.
    Total = (Only T)+(Only R)+(Only F)+(T&R only)+(T&F only)+(R&F only)+(All three)
    800 = 190 + 130 + 140 + [ (T&R only)+(T&F only) ] + (R&F only) + 160
    800 = 190 + 130 + 140 + [ 130 ] + (R&F only) + 160
    800 = 750 + (R&F only) => **R&F only = 50**.
*   **Find T&R only and T&F only individually using Total R = Total F:**
    Total R = (Only R) + (T&R only) + (R&F only) + (All three) = 130 + (T&R only) + 50 + 160 = 340 + (T&R only).
    Total F = (Only F) + (T&F only) + (R&F only) + (All three) = 140 + (T&F only) + 50 + 160 = 350 + (T&F only).
    Since Total R = Total F:
    340 + (T&R only) = 350 + (T&F only) => (T&R only) - (T&F only) = 10.
    We have two equations:
    1) (T&R only) + (T&F only) = 130
    2) (T&R only) - (T&F only) = 10
    Adding them: 2 * (T&R only) = 140 => **T&R only = 70**.
    Subtracting them: 2 * (T&F only) = 120 => **T&F only = 60**.

**Summary of Tourist Numbers:**
*   Only T = 190
*   Only R = 130
*   Only F = 140
*   T&R only = 70
*   T&F only = 60
*   R&F only = 50
*   All three = 160

Now, we answer the questions.

**11. How many tourists visited the Red Fort?**
*   Total R = (Only R) + (T&R only) + (R&F only) + (All three) = 130 + 70 + 50 + 160 = 410.
*   **Answer: (b) 410 tourists**

**12. The number of tourists visiting only one of the three places is?**
*   Only one = (Only T) + (Only R) + (Only F) = 190 + 130 + 140 = 460.
*   **Answer: (c) 460 tourists**

**13. The number of tourists who visited at least one of the Red Fort or Fatehpur Sikri is?**
*   This is everyone EXCEPT those who visited Only Taj Mahal.
*   Number = Total - (Only T) = 800 - 190 = 610.
*   **Answer: (a) 610 tourists**

**14. How many tourists have visited Taj Mahal and Fatehpur Sikri but not Red Fort?**
*   This is the definition of "T&F only".
*   Number = 60.
*   **Answer: (a) 60 tourists**

**15. The number of tourists who visited at least two places is?**
*   At least two = (T&R only) + (T&F only) + (R&F only) + (All three)
*   Number = 70 + 60 + 50 + 160 = 340.
*   **Answer: (a) 340 tourists**

### **Set 4: Class Test (Q.16 - Q.20)**

This set adds a Boys/Girls ratio to each region. The best approach is to create a table.

**Information Breakdown & Table Creation**

*   Total Students = 250
*   Let P=Physics, C=Chemistry, M=Maths.

| Region       | % of Total | Total Students | B : G | Boys | Girls |
|--------------|------------|----------------|-------|------|-------|
| Only P       | 16%        | 40             | 3 : 2 | 24   | 16    |
| Only C       | 24%        | 60             | 7 : 5 | 35   | 25    |
| Only M       | 30%        | 75             | 7 : 8 | 35   | 40    |
| P&C only     | 8%         | 20             | 2 : 3 | 8    | 12    |
| P&M only     | 9.6%       | 24             | 3 : 1 | 18   | 6     |
| All three    | 6%         | 15             | 2 : 3 | 6    | 9     |
| **C&M only** | **?**      | **?**          | **?** | **?**| **?** |

**Step 1: Find the total number for the missing region (C&M only).**
*   Everyone passed at least one subject.
*   Total = Sum of all regions
*   250 = 40 + 60 + 75 + 20 + 24 + 15 + (C&M only)
*   250 = 234 + (C&M only) => **C&M only = 16 students**.

**Step 2: Find the Boys & Girls for the missing region.**
*   Total Boys (B_T) + Total Girls (G_T) = 250
*   B_T - G_T = 14 (or G_T - B_T = 14, but we can assume more boys)
*   Solving these two equations: 2 * B_T = 264 => **B_T = 132**, so **G_T = 118**.
*   Sum of known Boys = 24+35+35+8+18+6 = 126.
*   Boys in C&M only = Total Boys - Known Boys = 132 - 126 = **6 Boys**.
*   Sum of known Girls = 16+25+40+12+6+9 = 108.
*   Girls in C&M only = Total Girls - Known Girls = 118 - 108 = **10 Girls**.
*   (Check: 6 Boys + 10 Girls = 16 students. Correct.)

Now we can answer the questions.

**16. What is the ratio B:G for Chemistry and Math but failed in Physics?**
*   This is the C&M only region.
*   Ratio = Boys : Girls = 6 : 10, which simplifies to 3 : 5.
*   **Answer: (a) 3 : 5**

**17. How many girls are there who passed exactly in one subject?**
*   Girls (Only P) + Girls (Only C) + Girls (Only M)
*   Number = 16 + 25 + 40 = 81.
*   **Answer: (d) 81**

**18. What is the total number of boys who passed exactly in two subjects?**
*   Boys (P&C only) + Boys (P&M only) + Boys (C&M only)
*   Number = 8 + 18 + 6 = 32.
*   **Answer: (b) 32**

**19. Girls (P&C only) is what percentage of Girls (C&M only)?**
*   Girls (P&C only) = 12
*   Girls (C&M only) = 10
*   Percentage = (12 / 10) * 100% = 120%.
*   **Answer: (c) 120%**

**20. Boys (only C) is what percentage of girls (only M or only P)?**
*   Boys (only C) = 35.
*   Girls (only M or only P) = Girls (Only M) + Girls (Only P) = 40 + 16 = 56.
*   Percentage = (35 / 56) * 100%.
*   Simplify the fraction: 35/56 = 5/8.
*   (5/8) * 100% = 62.5%.
*   **Answer: (c) 62.5%**
